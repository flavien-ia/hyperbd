# Les personnages : c'est /bd-perso

## Communication

- Détecte la langue de la personne et réponds TOUJOURS dans cette langue (par défaut : français).

Dis en une phrase que les personnages se font désormais avec `/bd-perso`, une
seule commande qui écrit le casting, le propose dans l'univers (l'auteur
retient ou écarte), puis dessine les retenus. Puis **charge la skill
`bd-perso` et suis-la** pour ce projet, avec les mêmes arguments.
